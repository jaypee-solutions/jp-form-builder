# Overview

`GLOSSARY.md` at the repo root is the canonical vocabulary. "Form" means only the reusable definition; its placement on a page is a Form embed. A Submission is one send and is not stored in v1; a stored Submission would be an Entry. Notifications go to Recipients, the Confirmation goes to the Submitter. The Mail layout frames every mail; a Body template is per Form.
